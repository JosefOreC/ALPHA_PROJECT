## 2. Propósito y justificación del proyecto

DistriRápido S.A.C. realiza más de 250 entregas diarias en diferentes distritos de Lima Metropolitana mediante una flota de 15 camionetas.

La empresa presenta problemas relacionados con la congestión vehicular, costos de combustible y mantenimiento, emisiones de CO₂ y entregas fuera de las ventanas de tiempo establecidas.

EcoLogística Lima busca desarrollar una plataforma web capaz de gestionar pedidos, vehículos y conductores, generar rutas optimizadas, visualizar recorridos mediante mapas, mostrar indicadores de sostenibilidad y generar reportes económicos y ambientales.

El proyecto representa una oportunidad para mejorar la eficiencia de las operaciones de última milla y reducir su impacto ambiental.

---

## 3. Objetivo general

Desarrollar un Producto Mínimo Viable (PMV) web para optimizar las rutas de reparto de última milla de DistriRápido S.A.C., considerando distancia, tiempo, consumo de combustible, emisiones de CO₂, ventanas de tiempo y restricciones operativas.
