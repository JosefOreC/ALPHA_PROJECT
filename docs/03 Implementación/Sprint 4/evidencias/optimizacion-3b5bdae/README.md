## Procedencia y resultados

Los JSON/TXT conservan sus fechas, comandos, códigos de salida y huellas originales. Las suites frontend, navegador y build se ejecutaron antes del commit sobre el código que se incorporó en él; el backend y su umbral se verificaron nuevamente sobre el commit de implementación. El [manifiesto](https://github.com/JosefOreC/ALPHA_PROJECT/blob/6e36e355e0d39c83c5700a83eb0987b6fd849a10/docs/03%20Implementaci%C3%B3n/Sprint%204/evidencias/optimizacion-3b5bdae/procedencia.json) registra las huellas de los artefactos y comprueba que el código del producto coincide con ese commit. No se reescribió el HEAD de los recibos anteriores.

El archivo .gitattributes de esta carpeta conserva los bytes de JSON, HTML, TXT y JPG sin conversión de fin de línea de Git. Los espacios originales de los informes y logs se preservan para verificar sus SHA-256; esta excepción se limita a los artefactos, sin afectar las reglas del código ni de Markdown.
